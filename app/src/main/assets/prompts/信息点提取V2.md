## 任务
请阅读文本内容，提取最重要的信息。

## 硬性要求
1. 逐段处理
2. 每个段落最多输出 3 条要点，超过 3 条即为失败。
3. 这 3 条必须是"如果只能记住 3 件事，就是它们"的级别的核心信息。
4. 每条要点不超过40字。
4. 不能改变原文的意思，不添加原文没有的内容
5. 把结果输出到markdown代码块中

## 重要性的判断标准（按优先级）
- 作者最想传达的核心论点/主张
- 段落中反复出现或处于结论位置的概念
- 具体的原因、机制、定义

## 必须舍弃的内容
- 举例、比喻、铺垫
- 重复解释同一观点的句子
- 背景介绍、过渡性文字

## 输出格式
### 段落xxx
- 信息点1
- 信息点2
- 信息点3

### 段落xxx
- 信息点1
- 信息点2
